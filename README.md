## ⚙️ Compilação

Os programas podem ser compilados utilizando um compilador compatível com C++.

Exemplo utilizando `g++`:

```bash
g++ main.cpp -o programa
```

Para executar:

```bash
./programa
```

Em sistemas Windows:

```bash
programa.exe
```

Para especificar uma versão do padrão C++:

```bash
g++ -std=c++17 main.cpp -o programa
```
